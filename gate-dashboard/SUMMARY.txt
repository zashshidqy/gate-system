================================================================================
                            GETTING STARTED
================================================================================

1. BACKEND SETUP
   cd gate-dashboard/backend
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   # Edit .env with your SERIAL_PORT paths
   alembic upgrade head

2. FRONTEND SETUP
   cd gate-dashboard/frontend
   npm install
   npm run build (optional)

3. RUN APPLICATION
   # Terminal 1: Backend
   cd gate-dashboard/backend
   source .venv/bin/activate
   uvicorn app.main:app --reload --port 8000

   # Terminal 2: Frontend
   cd gate-dashboard/frontend
   npm run dev

4. ACCESS DASHBOARD
   • Frontend: http://localhost:5173
   • API Docs: http://localhost:8000/docs
   • Health Check: http://localhost:8000/health

ENVIRONMENT VARIABLES (.env)

  SERIAL_PORT_EXIT=/dev/ttyUSB1
  SERIAL_BAUDRATE=115200

  JWT_SECRET=your-super-secret-key-min-32-chars
  JWT_ALGORITHM=HS256

================================================================================
                          TROUBLESHOOTING
================================================================================

CONNECTION ISSUES
  Problem: "Offline" status
  Solution: Check backend health: curl http://localhost:8000/health

  Problem: Gates show "Disconnected"
  Solution: Check USB: ls /dev/ttyUSB*

  Problem: WebSocket not connecting
  Solution: Check CORS and firewall settings

API ERRORS
  Problem: "Failed to send command"
  Solution: Check authentication token and command validity

  Problem: "Gate not connected" error
  Solution: Verify SERIAL_PORT configuration and USB connections

FRONTEND ISSUES
  Problem: Blank page or "Cannot GET /"
  Solution: Clear cache (Ctrl+Shift+Delete) and restart frontend

  Problem: Connection quality shows "Poor"
  Solution: Check network connection and backend performance
